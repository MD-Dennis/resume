# Dennis Kipngetich — Data Operations & AI Quality Portfolio

A responsive, single-page portfolio for international opportunities across data operations, data quality assurance, AI/ML data preparation, annotation quality, research operations, LLM evaluation, and AI safety.

## Files
- `index.html` — portfolio website
- `RESUME.pdf` — add your current resume PDF here before publishing

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with the professional email you want recruiters to use.
2. Add your final resume PDF to this folder and name it `RESUME.pdf`.
3. Verify role titles, dates, education/program wording, certification title, and employment/contract relationships against your resume and records.
4. Confirm the tools listed are tools you can discuss confidently.
5. Review every project description. They are labeled as proposed demonstrations using synthetic data, not completed client projects or employer deliverables. Build the demonstrations before changing their status or reporting results.

## Publish with GitHub Pages
1. Create a GitHub repository for the portfolio.
2. Upload `index.html`, `README.md`, and your `RESUME.pdf`.
3. In repository Settings, open Pages and configure deployment from the main branch and root folder.
4. Wait for GitHub Pages to provide the public URL, then test it in a private/incognito browser window.

Netlify can also host the folder as a static site. Keep a local copy of the source and resume.
