Selected work

Data quality and AI operations demonstrations

The projects below are proposed portfolio demonstrations using synthetic data. They are not client engagements or employer deliverables, and no production outcomes or performance metrics are claimed.

Demonstration 01 · Benchmarking

LLM response quality benchmark

Design a repeatable method for evaluating whether model responses follow instructions, answer the question, communicate uncertainty, and remain internally consistent.

  • Define a rubric with anchored scoring levels.
  • Create a balanced synthetic test set across common and difficult prompts.
  • Document scoring decisions and examples for each criterion.
Planned output: rubric, synthetic dataset, scoring guide, and a short analysis report. No performance results are claimed yet.
Demonstration 02 · Reliability

Hallucination and edge-case analysis

Explore how an assistant handles missing context, ambiguous requests, conflicting constraints, and questions that cannot be answered from the supplied evidence.

  • Build test cases with expected behaviors.
  • Classify failures such as unsupported claims and missed constraints.
  • Recommend targeted changes to prompts, rubrics, or evaluation coverage.
Planned output: failure taxonomy, annotated examples, and recommendations based on synthetic cases.
Demonstration 03 · Safety

Safe adversarial evaluation suite

Evaluate model behavior when instructions conflict, content is untrusted, or a prompt attempts to override the task’s stated boundaries.

  • Specify test objectives and safe boundaries.
  • Check instruction hierarchy and handling of untrusted text.
  • Record expected behavior, observed behavior, and severity rationale.
Planned output: test protocol and sample evaluation report. Test cases will avoid operationally harmful instructions.
Demonstration 04 · Human QA

Reviewer calibration and agreement

Create a small reviewer exercise that illustrates how clear guidelines and adjudication improve consistency on nuanced response-quality decisions.

  • Write decision rules and borderline examples.
  • Compare hypothetical reviewer ratings on the same items.
  • Identify disagreements and clarify the guideline.
Planned output: calibration guide, disagreement log, and a transparent agreement calculation using labeled synthetic data.
